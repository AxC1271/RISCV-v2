# AXI Bus Interconnect

## Purpose

We need a way for our CPU to interface external devices. As a standalone core, we can run some simple programs like running Fibonacci sequences. But what about interfacing with the outside world? Our applications then become very limited, and this is where AXI comes in.

AXI is an AMBA bus protocol 

---

## Design

Since we have multiple slave peripherals and one master peripheral, we need to use an interconnect which will serve as the bus for routing traffic to the correct destinations.
